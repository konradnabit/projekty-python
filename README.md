# Gra "Zgadnij Liczbę"

Aby zagrać w tę grę, wykonaj poniższe kroki:

1. **Pobierz repozytorium**:
   - Kliknij przycisk **Code** na GitHubie i wybierz **Download ZIP** lub sklonuj repozytorium:
     ```
     git clone https://github.com/konradnabit/projekty-python.git
     ```

2. **Zainstaluj Pythona** (jeśli jeszcze tego nie zrobiłeś):
   - Pobierz Pythona ze strony: https://www.python.org/downloads/

3. **Uruchom grę**:
   - W terminalu przejdź do folderu, w którym znajduje się pobrany plik `zgadnijliczbe.py`, i uruchom go:
     ```bash
     python zgadnijliczbe.py
     ```

Miłej zabawy!
